컴포넌트 기반 CSS 데모
(Component Scoped CSS nesting)

아래 카드들은 모두 .card 클래스를 가지며, 해당 컴포넌트 전용 스타일만 적용됩니다.

일반 카드 제목

이것은 기본 카드 컴포넌트입니다. 스타일은 .card 클래스 내부로 제한되어 있어, 외부 요소에는 영향을 주지 않습니다.

강조 카드 제목

이 카드는 .card.featured 클래스를 추가하여 강조 스타일을 적용했습니다. 왼쪽 주황색 테두리와 배경색이 변경되었습니다.

구매하기
⚠️ 이건 Alert 컴포넌트입니다. 카드와 완전히 다른 스타일이 적용됩니다.
✅ 성공 Alert 입니다. 변형 클래스로 색상만 변경했습니다.

이 제목은 .card 밖에 있으므로 카드 스타일이 적용되지 않습니다.

여기 있는 문단은 아무 클래스도 없어서 전역 스타일(body)만 적용됩니다.
