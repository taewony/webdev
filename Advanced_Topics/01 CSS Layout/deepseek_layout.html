⚡ nav ul { display: flex; gap: 42px; justify-content: center; }

🔒 고정 너비 컬럼 (250px → 280px로 강화)

width: 280px; + flex-shrink: 0;

✅ flex-shrink: 0 으로 인해 컨테이너가 아무리 좁아져도 절대 줄어들지 않습니다. (원래 250px에서 280px로 변경, 고정폭 개념 강조)

📏 옆의 가변 영역이 늘거나 줄 때 이 컬럼은 항상 280px 을 유지해요.

💡 핵심 고정폭 컬럼을 만들 때는 width 와 함께 flex-shrink: 0을 기억하세요.

⭐ 창 크기를 조절해 보세요! 오른쪽 영역만 부드럽게 변하고 이쪽은 그대로입니다.

🌊 가변 너비 컬럼 (flex: auto)

flex: auto; ⇢ flex-grow: 1; flex-shrink: 1; flex-basis: auto;

✅ flex: auto 는 "남은 공간을 전부 알아서 채워라" 는 의미입니다.

📐 옆에 280px 고정 컬럼이 자리 잡고, 나머지 폭을 이 영역이 100% 사용합니다.

🔍 관찰 브라우저 폭을 늘리면 이 영역만 커지고, 줄이면 이 영역만 작아집니다. 고정 컬럼은 요지부동!

⭐ 메인 컨테이너 display: flex; gap: 28px; 가 두 컬럼 사이에 일정한 간격을 만들어 줍니다.

📚 CSS 레이아웃 개념 노트 (Flexbox 중심)

🧩 1. Flex 컨테이너

  • display: flex; → 자식 요소들이 가로로 배치됨
  • gap: 28px; → 아이템 사이 간격
  • max-width, margin: auto로 가운데 정렬
  • 💡 main 태그가 flex 컨테이너 역할

📌 2. 고정 너비 컬럼

  • width: 280px; (기본 너비 지정)
  • flex-shrink: 0; → 작은 화면에서도 안 줄어듦
  • ✅ 고정폭 + 유연한 이웃 조합의 전형
  • flex-basis 대신 width 사용 가능

🌱 3. 가변 너비 컬럼

  • flex: auto; (flex-grow 1, flex-shrink 1, flex-basis auto)
  • 남은 공간을 모두 차지 → '스펀지' 역할
  • 컨테이너 크기 변화에 따라 실시간 리사이징
  • flex: 1; 과의 차이점: basis가 auto vs 0

🧭 4. 내비게이션 바

  • ul { display: flex; } 간편한 가로 정렬
  • justify-content: center; 중앙 배치
  • gap: 42px; 균일한 메뉴 간격
  • CSS 네스팅 사용 (nav ul li:hover 등)

🪆 5. CSS Nesting & box-sizing

  • nav ul { ... } 내부에 li 스타일 중첩
  • &:hover 로 부모 참조
  • box-sizing: border-box 전역 적용
  • 패딩을 줘도 너비가 늘어나지 않음

📱 6. 반응형 전환

  • @media (max-width: 680px) 적용됨
  • 화면이 좁아지면 main이 flex-wrap: wrap
  • 고정 컬럼이 100% 너비로 쌓임
  • 모바일에서도 내용 가독성 유지
