01. The Big Picture

거시적 배치 (Macro Layout) - 전체 화면의 뼈대를 잡는 방법

모든 것은 '박스'다

웹페이지의 화려한 디자인에 현혹되지 마세요. CSS의 관점에서 브라우저는 모든 요소를 크고 작은 '네모난 박스(Box)'로 인식합니다.

레이아웃 설계의 첫걸음은 화면 전체를 가장 큰 덩어리 박스들로 쪼개는 것입니다. Header, <main>, Footer 구역을 나누는 것이 그 시작점입니다.

이 큰 상자들 안에 점차 작은 상자(Component)들을 채워 넣는 것이 구조화의 핵심입니다.

<main> Container

페이지의 핵심 콘텐츠를 담는 가장 거대한 그릇입니다.

이 그릇 안에 우리가 만들 '히어로 배너', '최신 상품 목록', 'MD 추천 상품'과 같은 큰 블록(Component)들을 차곡차곡 담게 됩니다.

보통 max-width 속성을 주어 화면이 너무 넓어지더라도 콘텐츠가 한가운데에 보기 좋게 정렬되도록 기준점(Anchor) 역할을 수행합니다.

02. Flexbox & Details

미시적 배치 (Micro Layout) - Flexbox로 컴포넌트 내부 꾸미기

배치의 마술사, Flexbox란?

부모 요소에 display: flex를 선언하는 순간, 내부에 있는 자식 요소들을 마음대로 주무를 수 있는 1차원(가로/세로) 배치 시스템이 가동됩니다.

Flexbox의 핵심은 '부모가 자식을 통제한다'는 점입니다. 왼쪽, 가운데, 오른쪽 정렬은 물론이고 남는 여백을 어떻게 나눠 가질지 부모가 완벽하게 결정합니다.

과거의 복잡했던 화면 배치를 혁명적으로 쉽게 만들어준 현대 CSS의 표준 기술입니다.

Component 세로 배치 (Stacking)

기본 흐름 (Block)

블록 요소들은 원래 위아래로 자연스럽게 쌓이지만, 세밀한 간격 조절(margin)이 번거로울 때가 많습니다.

Flex Column 통제

가장 큰 부모인 <main>에 flex-direction: column을 선언하면 큰 컴포넌트들의 세로 배치를 직관적으로 지휘할 수 있습니다.

일괄 여백 (Gap)

gap: 80px 속성 하나로 여러 컴포넌트 사이의 간격을 완벽하고 일정하게 띄워줍니다. 마진이 겹치는 오류를 방지합니다.

Component 1: Hero Banner

거대한 <main> 영역에 담기는 첫 번째 부품, '히어로 배너' 내부를 살펴봅시다.

배너는 보통 커다란 배경 이미지 위에 주요 텍스트 내용이 정중앙에 위치해야 합니다.

이때 텍스트를 감싸는 배너 컨테이너에 display: flex와 함께 justify-content: center (가로 중앙), align-items: center (세로 중앙)를 적용하면 완벽한 십자 중앙 정렬이 완성됩니다.

Component 2: Product Group (다중 배치)

  • 가로 배치와 줄바꿈 (Flex Wrap) 카드를 감싸는 부모에게 display: flex를 주면 가로로 나열됩니다. 여기에 flex-wrap: wrap을 추가하면 자리가 부족할 때 카드가 자연스럽게 다음 줄로 넘어갑니다.
  • 크기 분할 계산 (Calc) 한 줄에 카드 4개를 꽉 차게 넣으려면 너비를 지정해야 합니다. width: calc((100% - 72px) / 4) 처럼 여백을 뺀 나머지를 수학적으로 계산하여 크기를 분배합니다.
  • 규칙적인 여백 (Gap) gap: 24px을 적용하면 카드와 카드 사이, 윗줄과 아랫줄 사이의 여백이 격자처럼 아주 일정하고 깔끔하게 유지됩니다.

Component 3: Product Card

이제 화면을 구성하는 가장 작은 단위인 '카드' 내부(Micro Layout)를 들여다볼 차례입니다.

카드의 상단에는 썸네일 이미지 영역이, 하단에는 상품 이름과 가격 같은 텍스트 정보 영역이 들어갑니다.

카드 내부 역시 flex-direction: column을 띠며, 정보 영역 안에서는 미세한 gap: 8px을 사용해 텍스트(제목, 가격) 사이의 간격을 정교하게 조율합니다.

Summary: Layout Flow

1. Main Container

전체 화면의 중심 뼈대를 잡고 콘텐츠 최대 폭 영역을 제한합니다.

2. Flex Column

섹션 단위의 거대한 컴포넌트들을 세로 방향(Column)으로 나열합니다.

3. Flex Wrap

다중 아이템(상품 카드)들을 가로로 나열하고(Wrap) 비율을 나눕니다.

4. Micro Layout

카드 내부의 작은 텍스트와 이미지 간격을 세밀하게 조율하여 완성합니다.
