🚀 과제 제출을 위한 GitHub Pages 배포 가이드

내가 만든 웹페이지를 전 세계 누구나 볼 수 있게 인터넷에 올리고, 교수님께 링크를 제출해 봅시다!

1

준비물 챙기기 (계정 및 프로그램)

코드를 올리려면 먼저 GitHub 계정과 코드를 전송해 줄 프로그램이 필요합니다.

  1. GitHub 홈페이지에 접속해서 회원가입(Sign up)을 진행해 주세요.
  2. PC에 Git이 설치되어 있어야 합니다. (설치되어 있지 않다면 여기서 다운로드 및 설치해 주세요.)
  3. 완성된 내 과제 폴더가 있어야 합니다.
    ⚠️ 중요: 메인 HTML 파일의 이름은 반드시 index.html 이어야 합니다!
2

GitHub에 원격 저장소(Repository) 만들기

내 코드를 보관할 인터넷 상의 폴더(저장소)를 만듭니다.

  1. 로그인 후 GitHub 메인 화면 왼쪽 위, 또는 우측 상단 + 아이콘을 눌러 [New repository]를 클릭합니다.
  2. Repository name에 과제 이름(예: web-programming-hw1)을 적습니다. 영문/숫자/하이픈(-)만 사용하세요.
  3. Public(공개)이 체크된 상태로 둡니다. (그래야 교수님이 볼 수 있습니다!)
  4. 다른 것은 건드리지 말고, 맨 아래 [Create repository] 초록색 버튼을 클릭합니다.
3

로컬 PC에서 GitHub로 코드 업로드하기

이제 VS Code(또는 터미널)를 열고, 내가 작업한 과제 폴더에서 아래 명령어들을 순서대로 입력합니다.

VS Code의 상단 메뉴에서 Terminal > New Terminal을 열면 됩니다.

터미널 명령어 (순서대로 한 줄씩 입력 후 Enter) 
git init
git add .
git commit -m "첫 번째 과제 제출"
git branch -M main

이제 방금 만든 GitHub 저장소의 주소를 연결하고 코드를 밀어넣습니다(Push).
(저장소 주소는 Step 2 완료 화면에서 https://github.com/내아이디/레포지토리이름.git 형태로 찾을 수 있습니다.)

저장소 연결 및 업로드 (자신의 주소로 변경하세요) 
git remote add origin 본인의_GitHub_저장소_주소.git
git push -u origin main
💡 처음 Git을 사용할 때 에러가 난다면? 이메일과 이름을 설정하라는 에러가 뜰 수 있습니다. 그때는 아래 명령어를 입력한 후, 다시 git commit부터 진행하세요.

git config --global user.email "내이메일@example.com"
git config --global user.name "내이름"
4

GitHub Pages로 무료 웹사이트 배포하기

코드가 잘 올라갔다면, 이제 이 코드를 웹사이트로 만들어주는(배포) 마법의 버튼을 누를 차례입니다.

  1. 내 GitHub 저장소 페이지에서 상단의 [Settings] (톱니바퀴 아이콘) 탭을 클릭합니다.
  2. 왼쪽 사이드바 메뉴에서 [Pages]를 클릭합니다.
  3. Build and deployment 항목 아래의 Branch 설정을 None에서 main으로 변경합니다.
  4. 옆의 [Save] 버튼을 누릅니다.
5

URL 확인 및 교수님께 제출하기 🎉

Save를 누른 후 약 1~2분 정도 기다려야 웹사이트가 생성됩니다.

  1. 1~2분 후 새로고침(F5)을 해보면, Pages 설정 화면 맨 위에 "Your site is live at https://..." 라는 문구와 함께 링크가 나타납니다.
  2. 해당 링크를 클릭하여 내가 만든 웹페이지가 잘 나오는지 확인합니다.
  3. 만약 404 에러가 뜬다면, 조금 더 기다렸다가 새로고침하거나 메인 파일 이름이 index.html인지 다시 확인하세요.
  4. 최종적으로 확인된 이 웹사이트 URL 주소를 복사하여 교수님(LMS 과제 제출란 등)께 제출하면 끝입니다! 수고하셨습니다.
