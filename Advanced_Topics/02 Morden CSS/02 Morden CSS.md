## 📄 [수업 자료] Modern CSS: 더 이상 디자인 도구가 아닌 강력한 프로그래밍 언어

과거의 CSS가 단순히 색상과 폰트를 입히는 '화장' 도구였다면, **Modern CSS**는 레이아웃, 상태 관리, 그리고 화려한 애니메이션까지 처리하는 웹의 핵심 엔진입니다.

---

### 1. 강력한 레이아웃 엔진 (Layout Control)

과거에는 복잡한 배치를 위해 `float`이나 `table`을 사용했지만, 이제는 직관적인 두 모델이 지배합니다.

* **Flexbox (1차원 정렬):** 가로 또는 세로 한 방향으로 요소를 유연하게 배치합니다. (예: 내비게이션 바, 중앙 정렬)
* **CSS Grid (2차원 정렬):** 행(Row)과 열(Column)을 동시에 제어하여 신문이나 매거진 같은 복잡한 레이아웃을 코드 몇 줄로 구현합니다.
* **Aspect-ratio:** 이미지나 비디오의 비율(16:9 등)을 자바스크립트 계산 없이 고정할 수 있습니다.

---

### 2. 동적인 변화와 데이터 관리 (Variables & Logic)

CSS 내에서도 변수를 선언하고 계산할 수 있어 코드의 재사용성이 극대화되었습니다.

* **CSS Variables (Custom Properties):** `--main-color: #333;`과 같이 변수를 선언하여 테마(다크 모드 등)를 쉽게 전환합니다.
* **`calc()` 함수:** 서로 다른 단위(예: `100% - 50px`)를 계산하여 동적인 크기를 지정합니다.
* **Container Queries:** 브라우저 창 크기가 아닌, **부모 요소의 크기**에 반응하여 스타일을 바꿉니다. (컴포넌트 중심 개발의 핵심)

---

### 3. 자바스크립트를 대체하는 상호작용 (Interactions & Validation)

"이걸 자바스크립트 없이 한다고?"라는 말이 나올 정도로 강력한 기능들입니다.

* **Form Validation:** `:invalid`, `:required` 등의 가상 클래스를 통해 사용자가 입력을 올바르게 했는지 실시간으로 확인하고 경고를 띄웁니다.
* **Scroll-driven Animations:** 스크롤 위치에 따라 요소가 움직이거나 나타나는 효과를 CSS만으로 구현합니다.
* **`:has()` 선택자:** 부모 요소를 선택할 수 있는 'CSS의 성배'라 불리는 기능입니다. 특정 자식 요소의 상태에 따라 부모의 스타일을 바꿀 수 있습니다.

---

### 4. 부드러운 사용자 경험 (Transitions & View Transitions)

사용자에게 앱 같은 매끄러운 경험을 제공합니다.

* **CSS Animations:** `@keyframes`를 이용해 복잡한 동작을 브라우저 최적화 성능으로 실행합니다.
* **View Transitions API:** 페이지를 이동할 때 요소들이 부드럽게 위치를 찾아가며 변하는 시네마틱한 효과를 제공합니다. (유튜브 영상의 핵심 강조 포인트)

---

### 5. 접근성과 사용자 배려 (Accessibility)

사용자의 환경 설정을 CSS가 존중합니다.

* **`prefers-color-scheme`:** 사용자의 OS가 다크 모드인지 감지합니다.
* **`prefers-reduced-motion`:** 애니메이션에 민감한 사용자를 위해 움직임을 최소화하는 설정을 인식합니다.

---
