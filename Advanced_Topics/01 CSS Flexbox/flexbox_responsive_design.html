📦 Flexbox 반응형 디자인 핵심 개념

Flexbox로 반응형 웹을 만들 때 꼭 알아야 할 4가지 원리를 직접 조정하며 확인해보세요.
브라우저 창 너비를 줄이고 늘리면서 각 데모의 변화를 관찰하세요.

① 줄바꿈 허용: flex-wrap: wrap

공간이 부족하면 아이템이 자동으로 다음 줄로 이동합니다. 반응형 카드 그리드의 기본기입니다.

카드 1
카드 2
카드 3
카드 4
카드 5
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.item { flex: 1 1 180px; } /* 기본 너비 180px, 늘어나고 줄어듦 */
💡 flex-wrap: wrap이 없으면 아이템들이 부모 너비를 넘어서거나 밀려납니다.

② 가변 크기 제어: flex-basis + flex-grow

flex: 1 1 150px; = 기본 150px, 남은 공간을 균등하게 분배(grow), 부족하면 축소(shrink).

flex: 1 1 150px
flex: 2 1 150px
(더 많이 늘어남)
flex: 1 1 150px
.item { flex: 1 1 150px; } /* grow, shrink, basis */
.item.special { flex: 2 1 150px; } /* grow 비율 2 → 공간을 두 배로 차지 */
🎯 flex-basis는 아이템의 기본 크기, flex-grow는 남은 공간을 나누는 비율입니다. 반응형에서 카드 너비를 유연하게 조절할 때 핵심입니다.

③ 방향 전환: flex-direction + 미디어 쿼리

모바일에서는 세로(column), 데스크탑에서는 가로(row)로 레이아웃을 쉽게 바꿀 수 있습니다.

항목 1
항목 2
항목 3
.container {
  display: flex;
  flex-direction: column; /* 모바일 기본 */
}
@media (min-width: 640px) {
  .container {
    flex-direction: row;
  }
}
📱 화면 너비가 640px 이상이면 가로로 배열됩니다. 창 크기를 조절해보세요!

④ 정렬 방식의 동적 변화: justify-content & align-items

미디어 쿼리를 이용해 화면 크기에 따라 정렬 방식을 바꿀 수 있습니다. 아래 예시는 800px 이상에서 space-between으로 전환됩니다.

A
B
C
.container {
  display: flex;
  justify-content: center; /* 기본 */
}
@media (min-width: 800px) {
  .container {
    justify-content: space-between;
  }
}
✨ 800px 미만에서는 아이템들이 중앙 정렬, 800px 이상에서는 양쪽 끝으로 벌어집니다. align-items도 같은 방식으로 반응형 적용 가능.

🎓 요약: Flexbox 반응형의 핵심 공식

“기본 크기(flex-basis) + 줄바꿈(flex-wrap) + 방향 전환(flex-direction)”
이 세 가지 속성만으로도 대부분의 반응형 패턴(카드 그리드, 내비게이션 바, 헤더/푸터 등)을 해결할 수 있습니다.
미디어 쿼리는 주로 방향 전환과 정렬 방식을 바꾸는 용도로 사용하면 됩니다.
