HSL 색상 모델 이해

1. HSL이란?

HSL은 색상을 Hue(색상), Saturation(채도), Lightness(명도)로 표현하는 방식입니다.

hsl(0,0%,30%)

2. HSL의 장점

  • 색상(Hue)만 따로 조절 가능 → 직관적
  • 밝기(Lightness) 조절이 쉬움 → UI 디자인에 유리
  • 색상 변형(hover, theme) 만들기 쉬움

3. Hue (색상: 0~360)

색상의 종류를 의미 (색상환 기준)

0° (Red)
120° (Green)
240° (Blue)

4. Saturation (채도: 0~100%)

색의 선명도 (0% = 회색, 100% = 진한 색)

0%
50%
100%

5. Lightness (명도: 0~100%)

밝기 (0% = 검정, 50% = 기본색, 100% = 흰색)

10%
50%
90%

6. 요약

  • Hue → 색상 종류 (빨강, 파랑 등)
  • Saturation → 색의 진함
  • Lightness → 밝기
