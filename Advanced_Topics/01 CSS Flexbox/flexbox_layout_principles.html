Flexbox 레이아웃의 마법 🪄

이 페이지는 CSS Flexbox의 두 가지 중요한 원리를 적용하여 만들어졌습니다.

1. 푸터(Footer)가 항상 바닥에 있는 원리

본문의 내용이 적어도 푸터가 화면 중간에 떠 있지 않고 바닥에 붙어있는 이유는 전체를 감싸는 #container에 있습니다.

  • min-height: 100vh;로 컨테이너의 최소 높이를 화면 가득 채웁니다.
  • flex-direction: column;으로 요소들을 위에서 아래로 쌓습니다.
  • 가운데 있는 main { flex: 1; }이 남는 빈 공간을 고무줄처럼 모두 흡수하여 팽창하므로, 그 밑에 있는 푸터를 바닥으로 밀어냅니다.

2. 본문과 사이드바가 나란히 배치되는 원리

main 요소 역시 자식들을 통제하는 Flex 컨테이너입니다.

  • 사이드바(snb)에 flex: 0 0 300px;을 주어 넓어지지도, 좁아지지도 않게 300px로 크기를 고정합니다.
  • 본문(article)에 flex: 1;을 주어 전체 너비에서 사이드바 300px을 빼고 남은 나머지 가로 공간을 모두 차지하게 만듭니다.
  • 모바일 화면에서는 flex-direction: column-reverse;를 사용하여 HTML 코드를 수정하지 않고도 본문이 위로, 사이드바가 아래로 가도록 시각적 순서를 뒤집습니다.
