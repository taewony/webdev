✨ ECMAScript 6 (ES6)
JavaScript 현대 문법 완전 정복

자바스크립트의 혁신적인 변화: 템플릿 리터럴, 블록 스코프, 상수, 화살표 함수, 전개 연산자 등을 직접 확인하세요
1 📄 템플릿 리터럴 (Template Literal)

백틱(`) 과 ${표현식} 을 사용해 문자열을 동적으로 생성합니다. 가독성과 편의성이 향상됨. 

let lang = "JavaScript";
let level = "고급";
let message = `지금 배우는 언어: ${lang}, 난이도: ${level}`;

let a = 15, b = 7;
let result = `${a} + ${b} = ${a + b} 입니다.`;
2 🔍 var vs let (스코프 차이)

var는 함수 스코프, let은 블록 스코프 {} 를 따릅니다. 아래 예제에서 차이를 확인하세요. 

// var: 블록 무시, 함수 레벨 스코프
var a = 0;
if (true) {
    var a = 2;    // 같은 변수 재선언 및 할당
    console.log("if 내부 var a =", a);
}
console.log("외부 var a =", a);   // 2로 덮어쓰기 됨

// let: 블록 레벨 스코프
let b = 0;
if (true) {
    let b = 2;   // 새로운 블록 스코프 변수
    console.log("if 내부 let b =", b);
}
console.log("외부 let b =", b);   // 0 유지
💡 let과 const는 블록 스코프이므로 의도치 않은 변수 덮어쓰기를 방지합니다.
3 🧊 const (재할당 불가 / 객체 수정 가능)

const는 재할당이 금지됩니다. 하지만 객체나 배열의 내부 속성은 수정 가능합니다. 

let c = 100;
c = 200;          // let은 재할당 가능
console.log("let 변경:", c);

const d = 100;
// d = 200;       // ❌ TypeError: 재할당 불가

const student = { eng: 90, kor: 100 };
student.eng = 80;    // 객체 속성 변경은 허용
console.log("student.eng 수정 후:", student.eng);

const backends = ["asp", "jsp", "php"];
backends.pop();      // 배열 메서드로 요소 제거 가능
console.log("backends 배열 변경:", backends);
⚠️ const는 변수 식별자의 재할당만 막습니다. 참조형 데이터의 내부 프로퍼티 조작은 가능합니다.
4 🏹 화살표 함수 (Arrow Function)

간결한 문법, () => {} 형태. 매개변수가 하나면 괄호 생략 가능, 리턴만 있으면 중괄호 생략 가능. 

// 1. 일반 함수 vs 화살표 함수
function add(a, b) { return a + b; }
const addArrow = (a, b) => a + b;

// 2. 매개변수 1개일 때 괄호 생략
const double = x => x * 2;

// 3. 즉시 실행 화살표 함수
(() => console.log("🏃‍♂️ 화살표 IIFE 실행됨"))();

// 4. 여러 줄 처리 시 중괄호 & return 필수
const multiplyAndLog = (x, y) => {
    const result = x * y;
    return `곱셈 결과: ${result}`;
};
5 🌟 전개 연산자 (Spread Operator) ...

배열이나 객체를 펼쳐서 병합하거나 복사할 때 사용. ES6에서 강력한 데이터 결합 도구 

// 배열 병합
const fruits = ["🍎", "🍊"];
const berries = ["🍓", "🫐"];
const allFruits = [...fruits, ...berries];

// 객체 병합 (뒤에 오는 속성이 덮어씀)
const obj1 = { one: 1, two: 2, other: 0 };
const obj2 = { three: 3, four: 4, other: -1 };
const mergedObj = { ...obj1, ...obj2 };

// 배열 복사 및 함수 인자 전달
const numbers = [10, 20, 30];
const maxNum = Math.max(...numbers);
✨ 전개 연산자는 기존 배열/객체를 변경하지 않고 새로운 데이터 구조를 만듭니다 (얕은 복사).

✅ ES6 핵심 정리 : let/const로 변수 관리, 템플릿 리터럴로 문자열 가독성 향상, 화살표 함수로 this 바인딩 및 코드 단축, spread/rest로 데이터 조작 간소화 등 모던 JavaScript 개발의 기초를 제공합니다.
