웹 프로그래밍에서의 구조적 사고

Semantic HTML + CSS Nesting + Design Token

1️⃣ Semantic HTML

  • header : 페이지 상단 영역
  • main : 문서의 핵심 콘텐츠
  • section : 주제 단위 콘텐츠
  • footer : 하단 정보

HTML은 "화면을 그리는 코드"가 아니라 문서의 의미 구조를 표현하는 언어입니다.

2️⃣ CSS Nesting

CSS를 HTML 구조와 동일한 계층으로 작성하면 코드 가독성이 좋아지고 구조적 사고가 자연스럽게 유지됩니다.

3️⃣ Design Token

Design Token은 디자인 값을 변수화한 것입니다.

  • color
  • spacing
  • radius
  • typography

예:

--color-primary
--space-md
--radius-card

이렇게 하면 디자인 시스템의 일관성을 유지할 수 있습니다.

4️⃣ 구조적 사고 (Structural Thinking)

좋은 웹 개발자는 웹페이지를 아래와 같은 계층 구조로 설계합니다.
  • HTML 구조
  • CSS 구조
  • 디자인 시스템
즉 
Design System
      ↓
Design Token
      ↓
CSS 구조
      ↓
HTML 구조
이 계층을 이해하면 대형 서비스 개발에 도움이 됩니다.
  • 대형 서비스 개발
  • React / Next.js
  • UI Component System
