📋 Page Generation Spec (DSL Format)

📝 DSL Specification:

                page: "Styled Text Example"
                layout: centered
                components:
                  - type: heading
                    content: "Hello World."
                    styles:
                      font-size: 72pt
                      font-family: "Cambria"
                      font-weight: bold
                      color: royalblue
                      text-shadow: drop-shadow

🎨 Tailwind CSS Implementation:

DSL to Tailwind Mapping:

  • font-size: 72pt → text-[72pt]
  • font-family: Cambria → font-['Cambria']
  • font-weight: bold → font-bold
  • color: royalblue → text-[#4169E1]
  • text-shadow → drop-shadow-lg

Combined Tailwind Classes:

class="text-[72pt] font-['Cambria'] font-bold text-[#4169E1] drop-shadow-lg"

🎯 Rendered Output

Hello World.

✅ DSL 스펙이 Tailwind CSS 클래스로 변환되었습니다.

모든 스타일 속성이 정확히 매핑되어 렌더링됩니다.

Full Page DSL Spec:

page: "Product Dashboard"
layout: grid-2-column
theme: light-blue
components:
  - type: header
    content: "Sales Analytics"
    styles:
      font-size: 48pt
      font-family: "Cambria"
      font-weight: bold
      color: navy
      text-shadow: subtle
  
  - type: metric
    title: "Revenue"
    value: "$125,430"
    styles:
      font-size: 36pt
      font-family: "Arial"
      color: green-600
  
  - type: chart
    data: monthly-sales
    styles:
      border: rounded-lg
      shadow: medium
