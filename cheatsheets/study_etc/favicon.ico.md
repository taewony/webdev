## 파비콘(Favicon)이란?

**파비콘**은 **favorite icon**의 줄임말로, 웹사이트를 대표하는 **작은 아이콘**입니다. 주로 브라우저 탭, 북마크(즐겨찾기), 주소창 옆 등에 표시되어 사이트를 시각적으로 식별할 수 있게 도와줍니다.

예를 들어:
- 네이버 탭에는 초록색 'N' 아이콘
- 구글 탭에는 'G' 문자 아이콘
- 이렇게 각 사이트마다 작은 로고가 보이는 것이 바로 파비콘입니다.

---

## 파비콘 연결은 무슨 의미인가요?

**파비콘 연결**이란, HTML 문서에서 브라우저에게 "이 웹사이트의 파비콘은 어떤 파일이고 어디에 있어"라고 알려주는 작업을 말합니다.  
즉, `<head>` 태그 안에 `<link>` 태그를 사용해 파비콘 파일의 경로를 지정해주는 것입니다.

브라우저는 이 정보를 바탕으로 해당 아이콘을 다운로드하여 탭이나 북마크에 표시합니다.

### 연결하지 않으면 어떻게 될까?
- 대부분의 브라우저는 웹사이트 루트(최상위 폴더)에서 자동으로 `favicon.ico` 파일을 찾으려고 시도합니다.
- 하지만 이 파일이 없거나 경로가 다르면 파비콘이 표시되지 않고, 기본 아이콘(지구본 모양 등)이 나타나거나 아예 표시되지 않을 수 있습니다.
- 또한, 다양한 브라우저와 기기(아이폰 홈 화면 등)에서 일관된 아이콘을 보여주려면 명시적으로 연결하는 것이 좋습니다.

---

## 실제로 어떻게 연결하나요?

가장 기본적인 방법은 HTML의 `<head>` 안에 다음과 같은 코드를 넣는 것입니다.

```html
<link rel="icon" href="favicon.ico" type="image/x-icon">
```

- `rel="icon"` : 이 링크가 아이콘(파비콘)임을 나타냅니다.
- `href="favicon.ico"` : 아이콘 파일의 경로입니다. 보통 루트에 `favicon.ico` 파일을 두고 이렇게 작성합니다.
- `type="image/x-icon"` : 파일 형식을 명시합니다. (ico 파일의 MIME 타입)

### 최신 트렌드: 다양한 포맷 지원
요즘은 다양한 해상도와 포맷( PNG, SVG )을 지원하기 위해 여러 줄을 추가하기도 합니다.

```html
<!-- 기본 파비콘 (ico) -->
<link rel="icon" href="/favicon.ico" sizes="any">

<!-- 32x32 픽셀 PNG 파비콘 -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">

<!-- 180x180 픽셀 애플 터치 아이콘 (아이폰 홈 화면용) -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

이렇게 하면 대부분의 브라우저와 기기에서 적절한 아이콘을 선택해 표시할 수 있습니다.

---

## 요약

- **파비콘** = 웹사이트를 대표하는 작은 아이콘.
- **파비콘 연결** = HTML에 `<link>` 태그를 추가해 브라우저가 그 아이콘을 찾아 표시하도록 하는 과정.
- 잘 연결하면 사이트의 전문성과 브랜드 인지도를 높일 수 있습니다.

가장 간단하게 `favicon.ico` 파일을 만드는 방법은 **온라인 변환기**를 사용하는 것입니다. 별도 프로그램 설치 없이 웹 브라우저만 있으면 몇 초 만에 만들 수 있습니다.

---

## 1. 온라인 변환기 사용하기 (가장 쉬움)

1. **준비물**: 파비콘으로 만들고 싶은 이미지 파일 (PNG, JPG, GIF 등).  
   - 이미지가 정사각형이 아니면 자동으로 잘리거나 늘어날 수 있으니 가능하면 정사각형 이미지를 준비하세요.
   - 나중에 작게 표시되므로 단순하고 선명한 디자인이 좋습니다.

2. **변환 사이트 접속**: 예를 들어 [**favicon.io**](https://favicon.io/) 또는 [**ConvertICO**](https://convertico.com/) 같은 무료 사이트를 엽니다.  
   - `favicon.io`는 텍스트로 아이콘을 직접 만들 수도 있고, 이미지를 업로드해서 변환할 수 있습니다.
   - `ConvertICO`는 이미지 업로드 후 바로 ICO 파일로 변환해줍니다.

3. **이미지 업로드 및 변환**:  
   - 사이트 안내에 따라 이미지를 업로드하고, 원한다면 크기나 배경 등을 설정합니다.
   - 변환 버튼을 클릭하면 잠시 후 `favicon.ico` 파일이 다운로드됩니다.

4. **파일 저장 및 적용**:  
   - 다운로드한 `favicon.ico` 파일을 웹사이트 루트 폴더(또는 원하는 위치)에 넣습니다.
   - HTML `<head>`에 다음 코드를 추가합니다.  
     ```html
     <link rel="icon" href="favicon.ico" type="image/x-icon">
     ```
   - 또는 파일 이름과 경로가 다르다면 그에 맞게 수정하세요.

---

## 2. 이미지 편집 프로그램 이용 (포토샵 등)

- **포토샵**:  
  1. 이미지를 열고 `파일 → 다른 이름으로 저장` → 포맷에서 `ICO` 선택 (포토샵은 기본적으로 ICO 저장을 지원하지 않을 수 있으므로, ICO 플러그인을 설치하거나 'Save for Web' 기능을 확인).
  2. 대신, 포토샵에서 여러 크기의 PNG로 저장한 후 온라인 변환기로 합치는 방법도 있습니다.

- **그림판** 등 기본 프로그램:  
  - 그림판은 ICO 저장을 직접 지원하지 않습니다. 대신 PNG로 저장한 후 위 온라인 변환기를 이용하세요.

---

## 3. 명령줄 도구 (고급)

- **ImageMagick**이 설치되어 있다면, 명령 한 줄로 변환 가능합니다.
  ```bash
  convert logo.png -define icon:auto-resize=16,32,48 favicon.ico
  ```
  이 명령은 16, 32, 48 픽셀 크기의 아이콘을 포함한 ICO 파일을 만듭니다.

---

## 💡 팁: favicon.ico에 포함하면 좋은 크기

브라우저 호환성을 높이려면 하나의 ICO 파일 안에 여러 크기의 이미지를 포함하는 것이 좋습니다. 온라인 변환기들은 보통 자동으로 여러 크기(16x16, 32x32, 48x48)를 생성해 하나의 ICO로 만들어줍니다.  
특별히 설정할 필요 없이 기본 옵션으로 충분합니다.

---

## ✅ 정리

**가장 간단한 루트**  
1. 정사각형 이미지 준비  
2. `favicon.io` 같은 무료 변환 사이트 접속  
3. 이미지 업로드 → 변환 → 다운로드  
4. HTML에 `<link>` 태그 추가  

이 방법으로 1분 안에 favicon.ico를 만들 수 있습니다.
